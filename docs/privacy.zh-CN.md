# 本地数据与隐私

Loci 将 Markdown、JSON 和附件保存在本地，不要求云端记忆数据库。Agent 可能把读到的内容发送给模型服务；本地存储不等于离线推理。

新克隆的个人大脑安装时，会禁用向原始公开 `codesstar/loci` remote 的推送，减少误操作。它不是加密或访问控制；备份、分享前仍须检查文件和目标权限。

`.loci/backups/` 的安装与升级备份可能包含私人指令和配置，不要公开。升级只管理程序文件，个人数据不在覆盖范围；见 [安装与回滚说明](AI-INSTALL.md)。

[操作手册](../LOCI-RULES.md) 要求敏感、含糊记忆先确认。这是行为规则，不能代替 Agent 权限设置或操作系统的文件保护。
