# 开始使用

[English](getting-started.md) · [中文首页](../README.md)

把这段话交给能操作本地文件和命令的 AI：

```text
帮我安装 Loci，按 https://raw.githubusercontent.com/codesstar/loci/main/docs/AI-INSTALL.md 操作。
已有大脑就复用，保留数据；最后验证实际接入。
```

需要 Node.js 18+ 和 Git，不需要 npm 包。安装器提供 Claude Code、Codex、WorkBuddy 的入口配置；新会话中验证实际加载。豆包工作、千问工作和 Qoder 已由维护者用 AI 接入指令验证连接已有大脑成功，由 AI 核实入口并配置。[验证范围](validation-0.6.1.md)。

可以试试：“以后用中文回复”“明天9点发材料，加到待办”“收藏这个链接”。第一次涉及记忆操作会完整读 `LOCI-RULES.md`；当前上下文里仍有效就复用，实际记录按需读。

直接说“帮我打开 Loci Dashboard，使用我现有的大脑”。AI 会找到已有安装并启动面板。服务需要保持运行；保存提醒和通知送达是不同环节。

已经在使用 Loci，要连接千问、豆包、Qoder 或新的 Agent？把 [这里的一段话](connect-existing-brain.md) 发给新工具即可，不用自己找路径。
