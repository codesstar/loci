# Maintenance direction / 维护方向

Current architecture: [one entry, one manual, on-demand data](architecture.md).

- Keep tasks, schedules, people, knowledge and project workflows stable.
- Verify additional clients before claiming native compatibility.
- Measure real first-use latency and instruction compliance with isolated synthetic data.
- Avoid new persistence modes, duplicated rulebooks, MCP or database layers in this refactor.

See [CHANGELOG](../CHANGELOG.md) for shipped changes; this list is future direction, not a claim of completion.
