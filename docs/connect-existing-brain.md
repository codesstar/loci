# 把新的 AI 接到已有 Loci

[用户手册](https://www.tryloci.com/handbook/#connect) · [第一次安装](AI-INSTALL.md)

已经在 Claude Code 或 Codex 里用过 Loci，后来又装了千问、豆包或其他 Agent？**直接在新工具里发送下面这段话。** 不用先回旧工具问路径，也不用重新下载一份大脑。

```text
我已经安装了 Loci，请把你连接到现有大脑。
请读取并执行：https://raw.githubusercontent.com/codesstar/loci/main/docs/AI-CONNECT.md
请你自己找到已有大脑并完成接入，保留数据，不要重复安装。
```

AI 会检查安装记录、找到大脑、核实当前客户端的接入方式，完成配置和只读验证。需要系统权限时，按客户端提示授权即可。

连接完成后，新开一个对话说：

```text
看看我在 Loci 里的待办。
```

看到与原工具一致的已有记录，就能确认新会话也读取了同一大脑。新增或修改一条真实记录后，还可以在原 Agent 或 Dashboard 核对。

## 一份大脑，多个入口

新增工具通常只增加连接；升级 Loci、迁移到另一台电脑是另外的操作。

当前有 Claude Code、Codex、WorkBuddy 的现成适配器。千问等客户端由 AI 根据可核实入口接入；豆包不同版本的能力仍需实际检查。客户端必须具备本地文件与工具能力，仅能上传附件或云端聊天的版本，无法通过一段提示词访问本机大脑。

AI 报告找不到大脑、没有权限或没有接入口时，让它说明具体原因，不需要自行创建第二份数据。执行细节已写在 [给 AI 的接入指南](AI-CONNECT.md) 中。
