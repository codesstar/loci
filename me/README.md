# me/ — Personal Profile

Everything about you — who you are, what you value, how you're doing, and what you've learned.

## Files
- `preferences.md` — Standing instructions for your AI: what to call you, language, tone, reply style (the only `me/` file loaded every conversation — keep it short)
- `identity.md` — Basic info, personality, background
- `values.md` — Stable values and decision principles
- `wellbeing.md` — Body, mental health, energy, sleep, confidence, and state
- `insights.md` — Fresh personal reflections (background · insight · why it matters · tentative impact · status)
- `learned.md` — Reusable lessons and practices
- `evolution.md` — Timeline of all past changes (Layer 3, never auto-loaded)

Goals live in root `plan.md`, not here.

## Rules
- Keep current files lean (`preferences.md` is Layer 1; the rest are Layer 2)
- A fresh reflection starts in `insights.md`; promote it to `values.md` or `learned.md` only once it's durable
- When something changes, update the current file AND append the old version to `evolution.md`
- `evolution.md` is append-only — it's your personal changelog
