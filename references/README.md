# Scraps and attachments

Scrap records live here; binary attachments live in `files/`. Use `scripts/loci-scrap.js` to add, find and edit items. The tool manages IDs, metadata and attachments. Existing legacy inbox entries are handled by its migration path.

The single operation guide is [LOCI-RULES.md](../LOCI-RULES.md#04--碎片链接与收藏). User-authored notes and research are indexed under `notes/`, and project research belongs to the corresponding project repository.
