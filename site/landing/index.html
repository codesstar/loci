什么是 LociWhat is Loci

不是又一个笔记软件 —
是给 agent 用的记忆层。 Not another notes app —
a memory layer for agents.

本地优先的结构化记忆。把 Loci 翻过来看 —— 五个侧面，点一下，每一面都亮起来。 Local-first structured memory. Turn Loci over and look — five facets, one click each, every side lights up.

01 · Remembers you 记住你
让你的 AI 真正记住你Your AI finally remembers you
无论 Claude Code、Codex 还是任何 agent —— 聊着聊着，它就在你无感之中，把对话沉淀成你的记忆。Claude Code, Codex, or any agent — as you talk, it quietly distills the conversation into your memory.
  • 不用复制粘贴、不用喊“记一下”，自动沉淀No copy-paste, no “save this” — it just settles in
  • 任何 agent 都接得上同一份记忆Any agent plugs into the same memory
  • 下次打开，它还记得你是谁、在做什么、项目进展到哪Next time, it still knows who you are, what you're working on, and where your project stands

02 · Keeps what matters 只存重要的
不是都记，只记对你重要的Not everything — only what matters
像记忆宫殿（Method of Loci）一样，Loci 把真正重要的蒸馏出来、分层归位：常用的随手在手边，旧的归档不打扰。Like the Method of Loci, it distills what matters and files it by layer — the active stays close, the old rests out of the way.
  • 智能路由：每句话落到对的地方Smart routing: every line to its right place
  • 分层 L1/L2/L3，越用越懂你而非越臃肿L1/L2/L3 layers — sharper over time, not heavier
  • 蒸馏成结构化笔记，从不存对话原文Distilled to structure — never raw transcripts

04 · Memory flows 记忆会流动
写一次，处处都认Write once, everywhere knows

  • 一个大脑，Claude Code 和 Codex 共用One brain, shared by Claude Code & Codex

  • 换工具不丢记忆，纯文本底座Switch tools, keep memory — plain-text core
